# 定时静默

运行总览 →「静默开关」卡片里的「定时静默」：按时间段自动让 AI 停下来，用来避开高峰价、省 token。
代码在 `src/silence-schedule.js`，数据存在 `state/silence-schedule.json`（0600，不进仓库）。

## 和手动静默的区别

| | 手动静默（「开启静默」按钮） | 定时静默 |
| --- | --- | --- |
| 什么时候 | 点了就一直静默，直到点「恢复正常」 | 按时间段自动开始、自动结束 |
| 群友消息 | 不交给 AI，也不记进未读 | 默认**照样记进未读**（不唤醒），恢复后 AI 能补看 |
| AI 的唤醒 | 仍会被定时唤醒（主动冒泡、睡醒、回复检查），**照样花 token**，只是发不出去 | 默认**一律不唤醒**，真正不花 token |
| 管理员私聊 | 不受影响 | 默认不受影响（可以勾选一起静默） |

两者同时存在时：**手动开关优先**。手动开启后一直静默；定时静默期间点「恢复正常」= **这一段临时恢复**（到这一段结束），下一段照常静默。

## 时间段

- 可以加多个，每个有自己的开关、名称、开始 / 结束时间。
- 哪些天：每天 / 工作日（周一至周五）/ 周末 / 自选（点选周一～周日，可多选）；都可以勾「跳过法定节假日」。
  内置节假日表只有放假日，调休补班的周末不算工作日。
- 跨午夜（如 23:00–07:00）以**开始那天**为准：「周五 23:00–07:00」= 周五晚到周六早。
- 天数和时刻按面板选的时区算（下拉带当前 UTC 偏移），与这台电脑的时区无关。
- 「一键填入 DeepSeek 高峰时段」：按「令牌与花费」的价目表填入北京时间工作日 09:00–12:00、14:00–18:00（跳过法定节假日——节假日本来就按空闲价）；已有同样的时间段不会重复添加。

## 静默期间（可勾选）

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 停止 AI 的一切唤醒 | 开 | 被 @、主动冒泡、睡醒、回复检查都不唤醒。关掉的话 AI 仍会被唤醒，只是发不出去（和手动静默一样花钱） |
| 群消息照样记下 | 开 | 记进未读但不唤醒；恢复后 AI 被唤醒时能看到这段时间说了什么（二代仿真） |
| 结束时补一次唤醒 | 开 | 静默期间有人 @ / 叫名字 / 提问 / 拍一拍 / 私聊找过 AI 的会话，结束时补唤醒一次；会话忙时排队 |
| 定时任务「叫 AI 来说」也暂停 | 开 | 发往群 / 好友的跳过这一次（不推迟），执行记录写「定时静默中」；任务表单里可以单独设「静默时段内：照常执行」；固定文字照发 |
| 管理员私聊也一起静默 | 关 | 默认你随时能和 AI 私聊 |

定时任务的编辑表单会在预览里标出「处在定时静默里，会跳过」的那几次。

## 和「定时任务免打扰」的关系

两条规则各管各的，只要有一条要求跳过就跳过，执行记录写明是哪条：
- 定时任务免打扰（定时任务页面）：时段内定时任务一律不往群里发——为了不打扰群友、防风控；
- 定时静默（这里）：时段内 AI 不工作——为了省钱；所以只暂停「叫 AI 来说」，固定文字照发。
